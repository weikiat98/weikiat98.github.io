Introduction

The Media Analytics Brief

As a data scientist at a media analytics firm, the objective is twofold: forecast movie revenues before a film's release, and recommend similar films to guide marketing, cross-promotion, and content curation strategies.

Supervised learning techniques are applied to develop a revenue prediction model, while a content-based recommendation engine is designed using movie metadata — genres, keywords, and overviews.

Lower heteroscedasticity is more important than RMSE for movie revenue prediction in business decision-making. A reliable model across all films outperforms one that only works for certain films.

Why Log Transformations?

Logarithm transformation is applied to runtime, revenue, budget, vote count, and popularity to reduce skewedness and dampen extreme outliers — particularly important for budget and revenue which can span many orders of magnitude.

Key Predictors (Highest Impact)

log_vote_count — Audience reviews are incredibly influential. Consumers read votes and reviews before deciding whether to watch. Platforms like Rotten Tomatoes can lead to early conclusions about quality, directly impacting revenue.

log_budget — Financial investment level matters. Higher budgets allow studios to promote films more extensively, increasing outreach to potential audiences.

Secondary Predictors

log_popularity — Strong social media buzz and studio-driven audience engagement campaigns translate directly to higher popularity scores and higher revenue. Avatar: The Way of Water's teaser garnered 148.6 million views in 24 hours.

log_runtime — Runtime has a positive influence on revenue earnings, but is less influential than budget and vote count.

Marginal Predictors (Lower Impact)

Keywords, genres, release_dayofweek — Content factors like keywords and genres play a less critical role than expected. A movie targeting multiple audience groups will still flop if marketing efforts are poor. Release day has some impact but is dwarfed by strong marketing outreach.

Real-World Evidence

Avengers: Infinity War alone allocated an estimated $150 million for promotional campaigns — its first trailer was viewed 230 million times in its first 24 hours. This exemplifies how budget directly fuels audience reach and vote count.

Conversely, excessive budget growth has diminishing returns. Disney's Snow White and Mulan live-action films, as well as Transformers: The Last Knight, bombed at the box office despite significant budgets — demonstrating that budget alone is insufficient without strong audience reception.

Question 1c

Content-Based Movie Recommendation System

A content-based recommendation system is designed using genres, keywords, and overview text. The system compares a movie's textual metadata against every other title and returns the five most similar recommendations with similarity scores.

System Architecture — 5 Steps

01
Prepare Text-Based Similarity Index
Copy the cleaned dataset and convert selected feature columns into plain text. List values are joined into a single space-separated string; missing values become empty strings. All columns are concatenated row-wise into one combined descriptive text per movie.
02
TF-IDF Vectorisation
A TF-IDF vectoriser is fitted on the combined text, turning each movie into a sparse numerical vector reflecting the importance of its words. English stop words are removed; unigrams and bigrams are both captured (ngram_range).
03
Case-Insensitive Title Lookup
A case-insensitive lookup dictionary is built from movie titles to their row indices, dropping duplicate lower-cased titles to avoid ambiguity.
04
Package Precomputed Assets
All precomputed assets (DataFrame, vectoriser, TF-IDF matrix, title index, original titles) are bundled into a single object. This avoids recomputing TF-IDF for every query, allowing fast cosine similarity lookups.
05
Cosine Similarity & Top-5 Recommendations
Cosine similarity scores are computed between the selected movie's TF-IDF vector and every other movie using linear_kernel. Scores are sorted in descending order, the movie itself is removed, and the top 5 are returned as (title, score) pairs. Fallback matching handles partial or inconsistent title input.
Figure 15: TF-IDF index builder — build_tfidf_index_tmdb()
def build_tfidf_index_tmdb(feature_cols, max_features=5000, ngram_range=(1,2)):
    # """Precompute TF-IDF and indices — reuse for recommend_tmdb() many times."""
    df = tmdb_cleaned.copy()

    # Per-column coercion: lists → "a b c", strings kept, else ""
    for col in feature_cols:
        df[col] = df[col].apply(
            lambda x: " ".join(x) if isinstance(x, list)
            else (x if isinstance(x, str) else "")
        )

    combined = df[feature_cols].fillna("").agg(" ".join, axis=1)

    tfidf = TfidfVectorizer(
        stop_words='english',
        max_features=max_features,
        ngram_range=ngram_range
    )
    tfidf_matrix = tfidf.fit_transform(combined)

    # Case-insensitive title index with duplicate-safe mapping
    titles      = df['title'].astype(str).fillna("Untitled")
    title_index = pd.Series(df.index,
                    index=titles.str.lower()).drop_duplicates()

    return {
        "df": df, "tfidf": tfidf,
        "tfidf_matrix": tfidf_matrix,
        "title_index": title_index, "titles": titles
    }
Figure 16: Content-based recommendation function — recommend_tmdb()
def recommend_tmdb(title, tfidf_bundle, topn=5):
    df          = tfidf_bundle["df"]
    M           = tfidf_bundle["tfidf_matrix"]
    idx_map     = tfidf_bundle["title_index"]
    titles      = tfidf_bundle["titles"]

    if not isinstance(title, str):
        return []

    idx = idx_map.get(title.lower())
    if idx is None:
        # Fallback: closest case-insensitive match
        candidates = [t for t in titles.unique()
                       if t.lower().startswith(title.lower())]
        if not candidates:
            idx = 0   # default to first movie
        else:
            idx = idx_map.get(candidates[0].lower(), 0)

    # Similarity of the query row vs all
    order = np.argsort(-sims)
    order = order[order != idx][:topn]
    return list(zip(titles.iloc[order].tolist(), sims[order].tolist()))

Question 1d

Insights, Deployment & Recommendations

Key Insights

Reviews & Budget Rule

Film vote counts and budget are the most critical predictors of revenue. Strong marketing drives higher audience engagement and votes.

Marketing Outreach

Social media buzz and audience reviews are critical in driving popularity, which translates to higher revenue earnings.

Release Day = Minimal

Release day of week has minimal impact. Even Friday or weekend releases remain subject to marketing campaign strength.

Diminishing Returns on Budget

Popularity and runtime positively influence revenue, but are less important than budget and vote count after logarithm transformation — highlighting the complexity of predicting revenue precisely. This contrasts with naive correlation analysis where each factor is plotted individually.

Deployment in Practice

Scenario 1: Cloud Batch Scoring
Random Forest regression deployed on Google Cloud Platform Vertex AI Batch Inference, targeting business analysts, studio executives, and marketing teams making high-stakes decisions. Relevant movie data is collected in a cloud storage bucket; a time-based batch job preprocesses data and generates predictions stored for "what-if" scenario analysis and resource optimisation (e.g., advertising spend allocation).
Scenario 2: Streaming Platform Recommender
Content-based recommendation system embedded directly into streaming or e-commerce platforms as a "More Like This" feature. A user who watched Iron Man gets recommended Iron Man 2 or Captain America: The First Avenger — improving viewer engagement, retention, and cross-promotion of other titles based on metadata like genres and keywords.

Improvement Recommendation

Add a Controversy Binary Feature

Include a binary feature indicating whether a film has been embroiled in controversies. With social media, controversies spread rapidly, damaging films and studio reputations. Disney's Snow White live-adaptation is a recent example — the lead actress's controversial behaviour divided the public, contributing to poor audience turnout.

Such a feature would allow the predictive model to learn the negative correlation between controversy and revenue, helping studio executives better assess risk, tailor marketing campaigns to mitigate negative press, and make more informed budgeting decisions.

  Methodology & Technical Details

Dataset

TMDB movie metadata dataset — pre-cleaned from group-based analysis. Features include movie budget, runtime, genres, keywords, overview text, vote count, popularity, revenue, and release dates.

Key Data Processing Steps

• Log transformation applied to skewed numeric features (budget, revenue, runtime, vote count, popularity)
• Temporal features extracted from release date (year, month, day, day-of-week, quarter)
• top_genre extracted as first genre per movie; 'Unknown' assigned when no genre found
• has_english binary flag added to capture language influence
• Correlation matrix used to drop low-signal features before model training
• Train/test split applied for unbiased model evaluation

Python Libraries Used

scikit-learn pandas numpy seaborn matplotlib TfidfVectorizer linear_kernel statsmodels

Evaluation Metrics

• RMSE (Root Mean Squared Error) — measures average prediction distance from actual values
• R² (R-squared) — measures proportion of variance in revenue explained by the model
• Breusch-Pagan Test — used to formally confirm presence of heteroscedasticity
• Parity plots & residual plots — visual inspection of model prediction quality
