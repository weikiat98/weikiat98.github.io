Task Execute the MySQL statement to count stores, analyse the result table, and compose a single MySQL query to update the shopper_profile table to rectify any anomalies observed.

The result is a table containing 2 columns with 15 rows. The store column contains types of stores, and n contains the count. The anomaly identified: "Osim" appears as a separate entry from "OSIM" due to case sensitivity — they should be the same store.

Step 02 — Rectify Anomaly
MySQL 
UPDATE shopper_profile
SET store = 'OSIM'
WHERE store = 'Osim';
MySQL — SQL Editor 
-- First, update the `store` column to change 'Osim' to 'OSIM' (question 1b)

SET store = 'OSIM'
WHERE store = 'Osim';

--run this code to double check--
SELECT store COLLATE utf8mb4_bin AS store,
COUNT(*) AS n
FROM shopper_profile GROUP BY 1;
Figure 6: SQL query to rename Osim to OSIM

After rectification, the number of rows decreased from 15 to 14, confirming the two entries have been merged. The total count for OSIM now correctly reflects the combined total.

Anomaly Found

The COLLATE utf8mb4_bin clause enables case-sensitive comparison, revealing that "Osim" and "OSIM" were counted as separate stores. A simple UPDATE statement standardises the casing.

Figure 13: Comparison of initial table data structure (top) and after changing data types (bottom)

Design Rationale

mall & store → VARCHAR(50): Text type is excessive; VARCHAR with a 50-character limit saves space while allowing flexibility for longer store/mall names.

gender → ENUM('Male', 'Female'): Only 2 distinct values exist. ENUM stores each value as a 1–2 byte integer internally, which is far more efficient than text.

race & citizenship → VARCHAR(25): Shorter text values than mall/store names. 25 characters provides sufficient flexibility.

age → TINYINT: Maximum age is 76. TINYINT supports 0–255, using only 1 byte versus 8 bytes for BIGINT.

Step 02 — Create 4 Plots

Four visualisations are created using ggplot2 with theme_economist() styling, then combined into a single visual using the patchwork library.

R — RStudio 
# Age Distribution by Mall (Remove legend, add labels)
age_dist_plot <- ggplot(shopper_profile, aes(x = age)) +
  geom_histogram(bins = 15, fill = "salmon", color = "white") +
  labs(title = "Age Distribution per Mall by Count", x = "Age", y = "") +
  facet_wrap(~ mall, ncol = 3) +
  theme_economist() +
  guides(fill = "none", color = "none") +
  stat_bin(bins = 15, geom = "text",
           aes(label = ..count..), vjust = -0.5,
           color = "black", size = 3) +
  theme(
    axis.text.x = element_text(size = 10),
    axis.text.y = element_text(size = 10)
  ) +
  scale_y_continuous(limits = c(0, 250))

R — RStudio 
# Calculate the percentage of each gender within each mall
gender_distribution_pct <- shopper_profile %>%
  group_by(mall, gender) %>%
  summarise(count = n()) %>%
  mutate(percentage = count / sum(count))

# Gender Distribution by Mall (Side-by-Side Bar Chart with Percentage Axis)
gender_dist_plot <- ggplot(gender_distribution_pct,
                           aes(x = mall, y = percentage, fill = gender)) +
  geom_bar(stat = "identity", position = position_dodge(width = 0.8)) +
  geom_text(aes(label = scales::percent(percentage)),
            position = position_dodge(width = 0.8),
            vjust = -0.5, size = 3) +
  scale_y_continuous(labels = scales::percent_format()) +
  labs(title = "Percentage of Gender Distribution by Mall",
       x = "Mall", y = "", fill = "Gender") +
  theme_economist() +
  scale_fill_manual(values = c("Female" = "#CD6090", "Male" = "steelblue")) +
  theme(legend.position = "bottom",
        axis.text.x = element_text(size = 10),
        axis.text.y = element_text(size = 10),
        legend.text = element_text(size = 10),
        legend.title = element_text(size = 10))

Key Findings — Analysis

Age Distribution

Universally right-skewed across all 6 malls — majority of shoppers are aged 20–40. 313@Somerset and Jurong Point have a larger proportion of younger shoppers (20–30), while Raffles City and VivoCity show a slightly broader age spread.

Gender Distribution

Jurong Point has the highest proportion of female shoppers. Centrepoint is the most balanced. Hougang Mall, 313@Somerset, and VivoCity lean towards a female majority. Raffles City shows the most balanced gender distribution overall.

Race Distribution

Universally dominated by Chinese shoppers across all malls. Jurong Point and VivoCity have slightly better demographic diversity with more Indian and Malay shoppers, though still representing a smaller portion.

Citizenship Status

Singapore Citizens make up the majority across all malls. SG PR and Student Pass holders are the minority. Jurong Point and VivoCity attract the most local shoppers. Student Pass holders have similar small proportions across all malls.
